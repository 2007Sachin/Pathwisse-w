# Pathwisse program catalogue verification

**Status:** Verification complete for the sources currently available  
**Page mode:** Mode B — Program philosophy / coming structure  
**Last reviewed:** 2026-09-20

## Verification conclusion

No authoritative Pathwisse program catalogue was found in the project workspace or publicly discoverable official Pathwisse pages. There is currently no verified basis for publishing program names, audiences, formats, durations, delivery modes, cohort models, prices, certifications, curricula, outcomes, eligibility rules, enrollment paths, or institutional delivery models.

The public Programs page must therefore explain where structured programs may fit within the Pathwisse employability approach without presenting any offering as commercially available.

## Sources reviewed

- `docs/product/PRD.md` — authoritative website scope; records the program catalogue and access model as unknown.
- `docs/product/POSITIONING.md` — strategic direction only; states that programs and capability-specific claims require verification.
- `docs/product/MESSAGING.md` — permits conceptual program positioning; requires catalogue, delivery, pricing, and outcomes to be validated.
- `docs/product/VOCABULARY.md` — permits “program” only for a verified structured offering.
- `docs/product/UX_PSYCHOLOGY.md` — positions programs as interventions within a wider journey, with all exact details requiring validation.
- `docs/product/HOMEPAGE_CLAIM_AUDIT.md` — prohibits publishing catalogue items, delivery formats, duration, pricing, or outcomes until verified.
- `docs/product/PATHWISSE_WEBSITE_BLUEPRINT.md` — strategic and speculative foundation, not catalogue proof.
- Existing source content and public assets — no authoritative catalogue records found.
- Official Pathwisse public pages discoverable on `pathwisse.com` and `app.pathwisse.com` — no named program catalogue or program-specific enrollment source found. Broad capability marketing on the sign-in page is not sufficient program evidence and is not adopted as verified website copy.

Old mockups, speculative documents, placeholders, generated page copy, and unrelated prototypes were excluded as evidence.

## Mode decision

**Selected:** Mode B — Program philosophy / coming structure.

Mode A is not permitted because no program has sufficient verified fields for public presentation. Mode B allows the website to explain the role of structured development without inventing a catalogue, implying enrollment availability, or exposing internal TBD values.

## Business confirmation required

Before switching to Mode A, approve at minimum:

1. Exact program name and current availability.
2. Intended audience and eligibility.
3. Purpose and bounded learning objectives.
4. Format, delivery mode, duration, and cohort model.
5. Curriculum and whether projects, mentorship, preparation, or industry participation are actually included.
6. Pricing publication policy.
7. Certificate type, issuer, and recognition boundaries.
8. Allowed outcome language and supporting evidence.
9. Enrollment or institutional inquiry path.
10. Content owner and review date.
